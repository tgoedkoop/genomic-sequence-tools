# genomic-sequence-tools
Python and R scripts for analysing and visualising genomic sequence data.
This repository contains utility scripts for basic computational genomics tasks. It is designed to demonstrate clean, documented, and reproducible data processing.

## Contents
* `gc_content_calculator.py`: A Python script to calculate the GC content percentage of a given DNA/RNA sequence.

## Prerequisites
To run these scripts, you will need:
* Python 3.8+
* R (with the `ggplot2` package installed)
* * `ucsc_bed_parser.py`: A Python script to parse standard UCSC Genome Browser BED files and filter genomic regions of interest based on sequence length.
